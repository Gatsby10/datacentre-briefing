# Bubble or Buildout

Weekly intelligence on AI data centres and networking. Built with Jekyll and served by GitHub Pages.

To publish a briefing, add a file to `_posts/` named `YYYY-MM-DD-title.md` with this front matter:

    ---
    layout: post
    title: "Week of 12 October 2026"
    summary: "One or two sentences on the week."
    verdict: "Buildout"
    ---
